# 📋 Design Documentation

Este documento contiene todo el proceso de diseno de Transcendence. Desde
la lluvia de ideas, las variaciones en las versiones, hasta llegar a la version final de la interfaz

Nuestra objetivo siempre fue crear una interfaz clara e intuitiva para el usuario, tambien priorizando la experiencia en cada una de nuestras pantallas

# 🎯 GOALS
- Crear una interfaz limpia y facil de usar.
- Asegurarnos de que todos los componentes fueran responsive en diferentes dispositivos.
- Un sistema de componentes escalable (leaderboard, friends, etc.).
- Coherencia visual entre pantallas para no romper la experiencia
